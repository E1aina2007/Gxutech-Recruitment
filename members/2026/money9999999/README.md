## AI 辅助记录

### 1. 我遇到的问题

第一次在 VS Code 上编辑 C++ 代码，写好了一个最基础的`Hello World!`程序后，点击右上角的运行按钮，终端报错提示找不到 `g++` 编译器，无法正常运行。


### 2. 我是怎么向 AI 提问的

我把 VS Code 终端里的报错截图发给了 AI，并提问：“我刚在 Windows 上安装好 VS Code，写好了一个 C++ 文件，但是点运行提示找不到 g++ 命令，请问怎么在 VS Code 里配置 C++ 运行环境？”

### 3. AI 的回答有没有直接解决？

AI 给出了具体方向，提示我需要先安装 MinGW-w64 编译器，并把它添加到 Windows 的系统环境变量中，然后要在 VS Code 里安装 C/C++ 插件。这个思路是对的，但我在实际操作时，由于环境变量配置后 VS Code 没有重启，导致依然报错。

### 4. 如果没有，我后来怎么继续处理？

发现按照 AI 的步骤尝试无效后，我没有继续盲目乱改，而是直接把问题和我的操作过程发给了实力强大的学姐。学姐非常耐心，给我发了一份详细的《VS Code C++ 环境配置文档》。我对照着文档，一步步排查路径、重新配置，最终成功跑通了第一个 C++ 程序。这次经历让我深刻意识到，自己折腾容易钻牛角尖，主动向学长学姐请教、学会查阅规范文档，是更高效率的成长方式。这也是我非常渴望加入技术组的原因之一，我想在这个有爱的氛围里，和大家一起学习和成长。
